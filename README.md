## 🎨 Official Color Palette Specification

The application implements the exact color mapping defined in `Color_Palette_Codes.xlsx`:

### Core Palette:
- **Dark Forest (`#3A463E`)**: Table headers, titles, section dividers, Rejection bars, and primary buttons.
- **Sage Green (`#6F867C`)**: Stage bars, active & interview metrics, header accent border.
- **Dusty Rose (`#B07A87`)**: Offers and hired numbers, overdue alert badges.
- **Wood Tan (`#B5A081`)**: Application source bars, Offer Received donut slice.
- **Soft Rose (`#C6A7AD`)**: Table header accent underline.
- **Sage Light (`#8BA195`)**: Secondary pill accents and text highlights.

### Tints & Supporting Shades:
- **Sage Tint (`#E4ECE6`)**: Table tint fills and input active backgrounds.
- **Sage Highlight (`#DCE8E0`)** & **Dark Green Text (`#2F4A3C`)**: Hired & Offer Received badges.
- **Rejected Fill (`#E5E7EB`)** & **Rejected Text (`#6B7280`)**: Rejected status badge.
- **Grey (`#AFAEAC`)**: Withdrawn status badge and donut slice.
- **Line Grey (`#DCE4DE`)**: Dividers and borders.

### Dark Mode Specification:
- **Background (`#1F2622`)**: Page body.
- **Card (`#29322D`)**: KPI and analytics cards.
- **Tint (`#34403A`)**: Input fields, alternating table rows, and borders.
- **Text (`#E9EFEB`)**: High-contrast readable typography.
- **Muted Text (`#9FADA5`)**: Secondary labels and metrics.
- **Rose Tint (`#46363A`)**: Soft alerts and upcoming indicators.

## ✨ Features

- **🌓 Dynamic Dark / Light Mode Toggle**: One-click switcher adhering to the exact light and dark specifications.
- **📊 Comprehensive KPI Metrics Deck**: Real-time stats on total applications, active pipelines, interviews, offers, hired, and rejections.
- **📈 Visual Analytics & Pipeline Breakdown**:
  - Stage distribution progress bars.
  - Interactive SVG Status Donut Chart with live legend.
  - Channel / Source efficiency charts (Campus Placement, LinkedIn, Referrals, etc.).
  - Rejection insights chart.
- **⚡ Filter & Search**:
  - Live full-text search across company name, role, salary, location, recruiter contacts, and notes.
  - Multi-criteria filtering by status, pipeline stage, and work style (Remote, Hybrid, On-site).
- **⏰ Smart Due Date & Follow-up Badges**: Highlights overdue interviews and upcoming follow-ups with color-coded alerts.
- **💾 Local Storage Persistence**: Automatically saves all changes locally in your browser. No server required.
- **🔄 Sync & Backup / Export**:
  - Download complete applications database as JSON.
  - One-click copy/paste backup and restore modal.

# 🎯 Pro Job Application Tracker

A modern, responsive, and standalone Job Application & Pipeline Tracker web application built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- **📊 Comprehensive KPI Metrics Deck**: Real-time stats on total applications, active pipelines, interviews, offers, hired, and rejections.
- **📈 Visual Analytics & Pipeline Breakdown**:
  - Stage distribution progress bars.
  - Interactive SVG Status Donut Chart.
  - Channel / Source efficiency charts (LinkedIn, Referrals, Job Portals, etc.).
  - Rejection insights chart.
- **⚡ Filter & Search**:
  - Live full-text search across company name, role, salary, location, recruiter contacts, and notes.
  - Multi-criteria filtering by status, pipeline stage, and work style (Remote, Hybrid, On-site).
- **⏰ Smart Due Date & Follow-up Badges**: Highlights overdue interviews and upcoming follow-ups with color-coded alerts.
- **💾 Local Storage Persistence**: Automatically saves all changes locally in your browser. No server required.
- **🔄 Sync & Backup / Export**:
  - Download complete applications database as JSON.
  - One-click copy/paste backup and restore modal.
- **🎨 Glassmorphic Dark UI**: Premium typography with Plus Jakarta Sans and JetBrains Mono, vibrant gradient accents, and responsive layout for mobile, tablet, and desktop.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Saicharan32175/JOB-TRACKER.git
   ```
2. Open `index.html` or `Job Application Tracker.html` directly in any modern web browser. No installation or build steps required!

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Glassmorphism tokens, responsive CSS Grid and Flexbox, custom SVG charts.
